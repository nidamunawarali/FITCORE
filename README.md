# FITCORE

FITCORE is a simple fitness landing page created as a mini project using HTML and CSS.

## Features

- Fitness-themed landing page
- Navigation bar
- Fitness registration form
- Call and Email buttons
- Background image and logo
- Responsive-style layout using CSS

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
